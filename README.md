# Swiggy SmartSplit

**A budget-aware food ordering concept for Swiggy**

SmartSplit is an independent product concept designed to help customers plan food orders within a fixed spending limit, including estimated delivery fees, platform fees, and taxes.

## Problem

Customers may discover at checkout that the final cost exceeds their intended budget, forcing them to edit their cart or abandon the order.

## Solution

SmartSplit lets users set a budget, explore menu items, track their estimated total in real time, and find item combinations that fit their spending limit.

## Core Features

- Budget selection and live remaining-budget tracking
- Interactive food menu and cart
- Itemised estimated charges
- Budget-matching meal recommendations
- Budget validation before simulated checkout

## How to Run

Open `index.html` in a modern web browser. No build tools or backend are required.

## Disclaimer

This is an independent product assignment prototype. It is not an official Swiggy product, and all menu data, prices, and fees are illustrative. No real orders or payments are processed.
